## 项目结论

当前网页版本只作为交互、动作与玩法原型保留，不再作为最终模型质量基线。最终角色必须在官方 Live2D Cubism Editor 中重新建立可编辑工程，源文件以经人工复核的分层 PSD 和 Cubism `.cmo3` 为准；`image2live2d` 自动生成的实验 `.cmo3` 不再作为正式交付物。

重制的首要目标不是增加更多会旋转的图片，而是让肩、肘、腕、腰、髋、膝、踝、袖口、裙片和披帛在运动中保持连续。角色中性姿态必须保持参考图的脸型、发型、配色、衣纹、鹤纹和整体剪影；运动姿态则以无裂缝、无重复残影、无透明漏底、无明显纹理拉断为独立验收目标。

## 素材基准与分层原则

参考图 `assets/source/reference.png` 是外观基准。现有透明母版可用于轮廓和原图 RGB 采样，但现有 `assets/layers/` 只作为辅助定位，不允许直接当作新的关节切片继续拼接。

新 PSD 使用一套完整身体底绘解决大动作露底：头部下方补全颈肩，袖子下方补全上臂和前臂，腰带下方补全胸腹与骨盆，裙摆下方补全双腿，所有被头发、衣袖、腰带和裙片遮住的区域都必须有可移动后仍成立的底片。相邻肢体不是沿可见边缘硬切，而是在遮挡区保留足够重叠，并让 Cubism 网格在重叠区连续过渡。

建议 PSD 层级如下，名称同时作为 Cubism Part ID 的中文语义来源：

| 组 | 必须分层的内容 | 连续性处理 |
|---|---|---|
| 头部 | 后发、发髻、左右侧发、前发、脸底、耳朵、眉、眼白、虹膜、瞳孔、高光、上睫毛、下睫毛、鼻、口腔、上下唇 | 脸底补全至发际线后方；眼皮使用睫毛网格闭合，不再用肤色块覆盖 |
| 躯干 | 颈、胸肩底绘、胸腹、骨盆、内衬、领口、腰带、腰绳、装饰 | 胸腹作为连续大网格；腰带独立但与躯干共用上级变形器 |
| 左右手臂 | 肩底片、上臂、肘遮挡、前臂、腕、手掌、拇指、其余手指 | 肩和肘保留隐藏重叠；Rotation Deformer 负责转动，Warp Deformer 修正体积 |
| 左右腿脚 | 髋底片、大腿、膝遮挡、小腿、踝、脚背、前脚掌 | 髋和膝补全；支撑脚参数独立，避免整人上下平移冒充走路 |
| 衣物 | 左右内袖、左右外袖、前裙、后裙、左中右裙片、内裙、腰侧衣片 | 固定端跟随身体，末端进入独立物理链；接缝处使用 Glue 或共享父变形器 |
| 飘带与配饰 | 上下披帛、腰带尾、发饰、耳饰 | 每条长物至少 3–5 段 Warp Deformer，根部高约束、末端低约束 |
| 场景 | 透明角色、竹林背景、仙鹤、前景花瓣分别交付 | Cubism 模型默认透明；场景交互由运行时组合，不烘焙进角色纹理 |

## Cubism 绑定结构

模型使用“全身大变形器 → 身体区域变形器 → 关节旋转变形器 → 局部 Warp Deformer → ArtMesh”的层级。大变形器负责整体重心和透视，旋转变形器只提供骨骼方向，局部 Warp Deformer 恢复肩、肘、膝等区域的体积和衣纹连续性。禁止让一整块上臂、裙片或头发只绕单点旋转后直接露出切口。

肩、肘、腰、髋、膝和踝使用加密网格；面部、眼皮、嘴和手指使用与轮廓方向一致的手工网格。长袖、裙摆和披帛的网格沿布料纹理走向布置，避免风动时花纹像橡皮一样横向拉伸。需要无缝贴合的相邻 ArtMesh 使用 Glue；会相互遮挡的部件使用 Clipping Mask 和明确的 Draw Order 参数。

## 参数、玩法与动捕

最终模型同时支持自动待机、键鼠/手柄操演、摄像头动捕和时间轴演出，不做成只能眨眼的展示模型。现有网页中的玩法定义可以迁移，但所有控制值都改为驱动 Cubism 标准参数，不再直接操作 PNG 图层。

参数至少覆盖头部三轴、身体三轴、呼吸、眼睛开合与视线、眉形、嘴形、左右肩肘腕、手指姿态、骨盆、左右髋膝踝、脚接触、袖摆、三组裙摆、披帛、发束和风场强度。动捕负责头、脸、上身与手臂；键鼠和手柄可以局部覆盖；腿脚与复杂手势可由操演快捷键或时间轴触发。中性待机保持视角固定，只允许呼吸、眨眼、轻微重心和二次物理运动。

物理链不以“2000 张发丝图片”冒充复杂度。头发按前发、侧发、后发和碎发分组，每组建立根部、中央、发梢三级以上输入输出；袖摆、裙片和披帛分别计算，风场统一输入。目标眨眼周期为 1.52 秒，运行时允许误差不超过 0.1 秒。

## 验收门槛

相似度与动画质量分开验收。中性姿态按透明角色区域对参考图做配准后的 alpha 加权图像比较，目标不低于 95%；面部另做局部比较，不能用把原图整帧画回去的方式过关。

动画验收覆盖头部三轴、最大抬臂、屈肘、转腕、鞠躬、重心转移、抬腿、支撑脚切换、强风、眨眼、说话和表情组合。肩、肘、腰、髋、膝、踝逐帧检查：不得出现舞台漏底、双重手脚、重复衣纹、透明裂缝或突然跳变；纹理接缝的局部差分必须连续。物理释放后必须有衰减回弹，不能是开关式位移。

正式完成的证据必须包括 Cubism Editor 实际打开并保存的 `.cmo3`、导出的 `.moc3 + model3.json + physics3.json`、中性和极限动作截图、自动验收报告，以及一次键鼠/手柄和一次动捕实测。未经过 Editor 打开的自动生成文件不得标记为完成。

## 实施顺序

第一阶段完成 PSD 重新分层和遮挡补绘，并用静态叠图确认中性姿态与参考一致。第二阶段在 Cubism 中完成面部和头部，再做躯干、四肢和脚锁；第三阶段完成头发、袖摆、裙片与披帛物理；第四阶段导出到现有网页运行时，迁移操演、动捕和时间轴；最后升级视觉验收，专门检测关节接缝、重复残影和大动作穿帮。
