# 竹鹤少女｜连续建模素材审计与重绘边界

> 记录日期：2026-08-26。本文是质量重置后的素材决策表，配合 `USER_ACCEPTANCE_SPEC.md` 使用。它不把任何旧 PNG 切层或候选图自动升级为可交付原画。

## 结论先行

现有 `bamboo-crane-maiden-source.psd` 可以保住中性画面，却不是可以直接扩展成自然全身动画的美术源。它的 31 个 PixelLayer 中，躯干只有一张、双臂各一张、双脚各一张、裙摆三张、披帛两张；面部只有头底、两张完整眼图与两张闭眼线。13 张 `Underpaint*` 是从覆盖区域补出的隐藏底图，并非按肩肘髋膝方向绘制的原画。它们可帮助定位接缝，但不得作为“关节已重绘”的依据。

参考图 `assets/source/reference.png` 是唯一的外观裁决源。候选 `assets/source/candidates/identity-preserved-fullbody-v1-alpha.png` 只提供无背景、可观察的全身结构：它生成时保持了相近的发型、手势、衣摆和双脚，但脸部线条、衣纹和剪影都可能有生成差异。因此它只能用于隐藏底绘的形状参考，或在完全被上层原始纹理覆盖的区域取色；不能替换参考图、现有运行时主纹理或静态相似度评分母版。

## 面部：先完成静态审阅的最小层组

脸不能继续以一张“眼睛贴片”加一张“闭眼贴片”来处理。新面部组以参考图的自然比例为锚点，并按左右分别拆出脸底与耳、眉、上眼睑/上睫毛、下眼睑/下睫毛、眼白、虹膜、瞳孔、高光、鼻与口。开眼时各层合成必须与参考脸一致；闭眼时由上下眼睑形变完成遮盖，闭眼线只做最后的细线，不允许用肤色椭圆盖住整眼。

当前 1254px Cubism 画布里的旧眼部审核窗口可先沿用：左眼 `x=580–630, y=254–306`，右眼 `x=631–679, y=253–306`。这两个窗口只是当前像素层的包围范围，不是最终网格边界；重绘时每侧向四周至少保留 10–14px 的肤色、眼睑和睫毛过渡区。静态脸部第一道门只看三个画面：开眼中性、半闭约 50%、完全闭合。先由肉眼确认眼宽、眼高、眼距、虹膜位置和高光没有放大或漂浮，再进入头部角度和视线。

| 骨盆与双腿 | 双腿被裙摆遮挡，只有脚切片 | 内裙、左右髋、大腿、膝、小腿、踝、脚背与鞋底接触面 | 重心左/右移、抬腿、支撑脚切换 |

| 头发与发饰 | 发根/发梢只分两片 | 前发、左右侧发、后发、发髻、碎发、发饰，根—中—梢三级 | 头部微动、风场、停止后回弹 |

重绘第一轮只要求前后遮挡、体积和纹理连续，不追求大角度转身或逐指表演。关节相邻层必须在不可见区有足够重叠，固定端归身体控制，自由端才进入物理；所有“看不见的补绘”在中性姿态必须被正确上层完全遮住。任何把候选图的可见纹样直接盖到参考母版上的方案都要先停下，因为那会用静态相似度换来新的纹样断层。

## 推演后的建模批次

一次批次只解决一条依赖链，但不再点一下就验证一次。面部批次连续完成源层命名、裁边、Draw Order 和三张静态预览后统一审阅；单关节批次连续完成底绘、局部 Warp、正反极值和中间值后统一抓取四帧。只有出现父级错挂、素材可能丢失或视觉门失败时，才中途停下来检查。

第一批实际重建顺序是面部、颈肩—躯干、右侧抬手臂、左侧下垂手臂、骨盆—双腿—脚、衣发物理。这个顺序先解除老板已经明确指出的夸张眼与贴片肩问题，同时保证后续手、脚与衣摆都接在能承受重心变化的躯干上；不能为了快速看到衣摆飘动跳过腿脚和躯干。

## 通过与拒绝的证据

每个新层组要保留其来源、隐藏区说明和中性合成图；每条关节链要保留 `-1 / -0.5 / 0 / +0.5 / +1` 五档截图或等效连续视频。中性比对至少 95% 且通过脸部/剪影人工检查，只能证明该静态状态；关节、Physics 和操演还须各自通过后才能登记为完成。任何“Viewer 能打开”或旧 Canvas 原型绿灯只登记为运行时兼容证据，永远不替代本表的视觉证据。
